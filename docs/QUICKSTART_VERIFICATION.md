## 复现入口

在解压目录运行：

```bash
bash '安装 ClipAgent.command'
bash '启动 ClipAgent.command' --check
bash '启动 ClipAgent.command' --port 8875 --no-browser
```

使用终端显示的本地地址打开浏览器，完成后按 Ctrl+C。构建者可在仓库根目录运行 `.venv/bin/python -m scripts.package_quickstart` 重建 ZIP 和 SHA256 文件。
